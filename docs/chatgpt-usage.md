# Use Brancha across chats

Select your connected Brancha plugin in a new ChatGPT chat, then say:

> Use Brancha for this chat. List my projects and resume the project I name. Save meaningful decisions, branches, evidence and next steps without asking each time. Before I switch projects, checkpoint meaningful unsaved work in the outgoing project and resume the named incoming project. Preserve original requests and do not create duplicate projects. Reread the current revision before each write because other chats may be working too.

An explicit existing project name is enough to switch. Ask only when the intended project is ambiguous. A switch without new work needs no empty checkpoint. Records remain self-reported sources until evidence supports stronger claims.

For another window or device on the same account, select the same connected plugin and use the same service. Resume afresh rather than copying an old workspace snapshot. Keep each chat's active project in that chat; simultaneous chats can work on different projects. A conflicting write requires a fresh read and reconciliation. A new checkpoint gets a new request ID; a retry keeps its original ID and content.

Another account, workspace, AI provider or custom GPT needs a compatible authenticated tool connection of its own. A copied instruction is not an installed integration. Do not put local service credentials into prompts, public packages or custom instructions. The owner-private deployment does not automatically grant another account access.

The ChatGPT workflow runs within an activated conversation. It does not passively observe every conversation. Local Codex capture is a separate service; the optional bridge appends cloud checkpoints to the local record and generated Obsidian views while the Mac is online.

For a daily review, inspect only accessible chats in the requested local date range. A chat's updated timestamp is not proof that work completed that day. Preserve source timestamps, mark active runs as pending, flag unavailable content, and keep unmatched chats separate rather than guessing from a shared directory. Summarise approved project changes; do not upload full captured transcripts.
