# Full-page project and chat maps

Choose **Full-page map** in a project or chat dashboard. This opens a dedicated note in Obsidian or the same generated page on localhost.

- **Mindmap**: expand or collapse a category by clicking its box, or use Expand all / Collapse all. Maps with more than 40 records start with collapsed branches to keep the overview usable. Search opens matching branches. Select a record for details and source links.
- **Flow / dependencies**: shows every record and every explicit saved relationship within this project or chat, including unconnected and parked records. There is no 24-record preview cap. Use Focus connected records for a selected neighbourhood, then Show whole map to return.
- **Fit whole map** shows the complete diagram. **Readable size** restores larger labels with horizontal and vertical scrolling. Zoom and keyboard-accessible boxes work in either mode.
- The diagnostic dropdown counts records, saved connections and unconnected records; select an unconnected record to inspect it. Unconnected does not mean erroneous.
- **Project dashboard** or **Chat dashboard** returns to the originating scope. Home and project/chat selectors remain available.

Mindmap grouping lines are navigation, not work dependencies. Dependency arrows preserve saved direction; dashed lines mean context. Chat flows use only explicitly recorded relationships between records attributed to that exact chat. Captured requests, replies and file references remain available as unconnected source material until an explicit relationship exists. Selecting or expanding an item does not change status or accept a suggestion.

Both views use the same local data, renderer and privacy filter. New saved work refreshes the open map while the companion runs. Dense maps require scrolling; long labels wrap with a full-title tooltip. Edge labels appear directly on small graphs; every connection is labelled in the selected-record panel for dense graphs. Cycles remain visible in a shared column. This is a deterministic view, not an additional AI analysis or autonomous improvement agent.
